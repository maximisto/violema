# Violema

[Violema](https://violema.com/) is a scientific evidence company. It builds systems that connect scientific claims to their sources, make assumptions visible, and keep conclusions open to review. [PsychDoc.AI](https://psychdoc.ai/) is its first application.

## Looking for the former AI coworker?

The AI operator previously called Violema is now **[Purple Orange Agent](https://agent.purpleorange.ai/)**, a product of [Purple Orange AI](https://purpleorange.ai/). Use that site for the operator product.

| Current name | Purpose | Website |
|---|---|---|
| Violema | Scientific evidence company | [violema.com](https://violema.com/) |
| Purple Orange Agent | The former Violema AI coworker/operator | [agent.purpleorange.ai](https://agent.purpleorange.ai/) |

## This repository

- [`company-site/`](company-site/README.md) contains the scientific company website and its build, preview and validation instructions.
- [`frontend/`](frontend/) and [`backend/`](backend/) retain code from the former operator application. Their directory names and historical Violema references do not describe the current company website or establish the current Agent deployment source.
- [`docs/products/`](docs/products/README.md) and the [Agent Studio manual](docs/AGENT_STUDIO_MANUAL.md) retain earlier operator/Agent Studio split plans. In those historical documents, “Violema” refers to the former operator, now Purple Orange Agent. They are not current scientific-company positioning or deployment instructions.

For the current company and charter, see [Violema About](https://violema.com/about/). For repository operating rules, read [AGENTS.md](AGENTS.md) and [CLAUDE.md](CLAUDE.md). Production deployment requires a separate explicit request.
