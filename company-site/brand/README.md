PsychDoc’s current mark is the two-leaf artwork. Both SVG path sets were checked against the live psychdoc.ai header on 2026-10-15. The neon brain/circuit icon is retired and must not be reused. An old checkout is not a brand source of truth.

Do not redraw, recolour or regenerate this artwork. Earlier Violema variants and their dated provenance are in [the archive](../archive/brand-concepts-20261010/README.md), outside the active asset directory. The current site build never publishes that archive.
